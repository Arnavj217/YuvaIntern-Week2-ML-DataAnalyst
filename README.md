# Week 2 — Data Collection, Preprocessing & Cleaning

## 📌 Overview

Week 2 focused on transforming agricultural data from raw, inconsistent records into structured and analysis-ready datasets. The work emphasized data quality because reliable analytics and machine learning depend on properly prepared input data.

The week covered data collection, data inspection, missing-value treatment, duplicate removal, categorical standardization, derived variables and preparation of machine-learning-ready data.

## 🎯 Objectives

* Identify suitable agricultural datasets.
* Understand the structure and quality of raw data.
* Detect missing values and duplicate records.
* Standardize inconsistent data entries.
* Handle missing and invalid values.
* Prepare clean datasets for analysis.
* Create a documented preprocessing workflow.

## 🔍 Key Activities

* Researched publicly available agricultural datasets.
* Worked with crop production, rainfall and market-related data structures.
* Inspected data types and dataset structure.
* Identified missing values.
* Removed duplicate records.
* Standardized categorical variables.
* Investigated outliers and inconsistent observations.
* Derived analytical variables where required.
* Created cleaned datasets.
* Prepared machine-learning-ready data.
* Documented all major preprocessing decisions.
